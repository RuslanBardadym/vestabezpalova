# Убрать лишние кнопки «Написать Весте»

Цель: не провоцировать поток пустых вопросов в личку. Общая кнопка «Написать Весте» остаётся только там, где обращение — осмысленное действие; дубли и кнопки «на всякий случай» убираются.

## Что убираем

### 1. Страница продукта (`src/routes/programmy/$slug.tsx`)
- В нижнем призыве «Готовы начать?» остаётся ОДНА кнопка:
  - для продуктов с оплатой (квест, аудит) — только «Купить» (WayForPay);
  - для остальных — только «Получить доступ».
- Убираются: «Написать Весте» (button-outline) и «Задать вопрос».
- Подпись-подсказка под кнопкой «Купить» («После оплаты напишите Весте в Telegram…») остаётся — это инструкция, а не кнопка.

### 2. Главная (`src/routes/index.tsx`)
- Шапка сайта: кнопку «Написать Весте» убираем — остаётся чистая навигация (Программы / Наставничество / О Весте).
- Финальный экран («Дар. Профессия. Масштаб.»): убираем «Написать Весте», остаётся одна кнопка «Смотреть программы».

## Что оставляем (целевые обращения, а не «написать что угодно»)
- «Помочь мне выбрать» — блок «Не знаете, с чего начать?».
- «Обсудить наставничество» — блок наставничества.
- «Оставить запрос» — блок поездок по местам силы.
- Telegram-блок «Бесплатное обучение» — без изменений.

## Не трогаем
Контент, цены, мокапы, дизайн-систему, навигацию по темам, страницы программ (кроме кнопок в нижнем призыве).

## Проверка
Playwright 390 / 1440: на странице продукта одна кнопка действия, на главной нет дублей «Написать Весте», целевые кнопки работают, ошибок нет.
