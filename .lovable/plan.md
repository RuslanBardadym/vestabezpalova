# Оценка разработки образовательной платформы Весты Беспаловой

## Что входит в оценку

Полная платформа, а не только сайт:

- Публичный многостраничный сайт (главная, каталог, страница продукта, блог, бесплатные материалы, отзывы, FAQ, календарь, контакты, юрстраницы).
- CMS/база данных для управления продуктами, статьями, отзывами, FAQ, расписанием.
- Пользовательская аутентификация (регистрация, вход, восстановление пароля, личный кабинет).
- Встроенная оплата и автоматическая выдача доступа к купленным материалам.
- Email-уведомления (подтверждение регистрации, чек, доступ к продукту).
- Адаптивная вёрстка, SEO-оптимизация, страницы 404 и успешной оплаты.
- Админка для команды эксперта без привлечения разработчика.

## Фазы и трудоёмкость

### Фаза 1. Подготовка и проектирование
- Уточнение структуры, дизайна, типов продуктов, форматов доступа.
- Создание базы данных, таблиц, RLS-политик, ролей.
- Подключение Lovable Cloud (аутентификация, база данных, хранилище, email).
- Подключение платёжной системы (Lovable Payments / Stripe / Paddle).

### Фаза 2. Публичный сайт
- Главная страница с блоками: герой, об эксперте, каталог, доверие, CTA, соцсети.
- Каталог продуктов с фильтрами по направлениям, категориям, типам.
- Типовая страница продукта с программой, тарифами, отзывами, FAQ.
- Блог со списком статей и страницей статьи.
- Бесплатные материалы, отзывы, FAQ, календарь, контакты, юрстраницы.
- SEO-заголовки, описания, Open Graph, адаптивность.

### Фаза 3. Авторизация и личный кабинет
- Регистрация, вход, восстановление пароля, подтверждение email.
- Личный кабинет с купленными продуктами и доступом к материалам.
- История заказов и профиль пользователя.

### Фаза 4. Оплата и автоматизация
- Интеграция checkout (Stripe / Paddle / Lovable Payments).
- Обработка успешной оплаты и webhook-уведомлений.
- Автоматическая выдача доступа к продукту после оплаты.
- Email-письма: чек, доступ к материалам, напоминания.

### Фаза 5. Админка / CMS
- CRUD для продуктов, статей, отзывов, FAQ, событий календаря.
- Управление ценами, доступностью, публикацией.
- Просмотр заказов и пользователей (безопасно, с ролями).

### Фаза 6. Тестирование, доработки и запуск
- Проверка сценариев: посетитель → продукт → оплата → доступ.
- SEO, скорость, мобильная адаптивность.
- Исправления и доработки по обратной связи.

## Оценка в кредитах Lovable

```text
Предупреждение: точное число кредитов нельзя предсказать.
Стоимость сборки в build mode зависит от сложности, количества итераций
и объёма работы. План mode расходует 1 кредит за сообщение.
```

Ориентировочная шкала для проекта такого масштаба:

- Подготовка и архитектура: ~5–15 сообщений в build mode.
- Публичный сайт (10+ типов страниц): ~20–50 сообщений.
- Авторизация и личный кабинет: ~10–25 сообщений.
- Оплата и webhooks: ~10–25 сообщений.
- Админка/CMS: ~15–35 сообщений.
- Тестирование и доработки: ~10–30 сообщений.

**Итого: очень примерно 70–180 сообщений в build mode + планирование (1 кредит/сообщение).**

Это означает, что для комфортной реализации без спешки лучше иметь запас по кредитам: Business-план или выше, либо использовать daily/месячные кредиты с возможностью докупки.

## Оценка в деньгах ($)

### Подписка Lovable
- Для платформы с оплатой, базой данных и CMS нужен платный план (Pro минимум, комфортнее Business или выше).
- Pro: от ~$20–50/мес в зависимости от тира.
- Business: от ~$100–300/мес для команд и больших проектов.
- Enterprise: индивидуально.

### Lovable Cloud (бэкенд, база, хранилище, email)
- Входит $25 бесплатного баланса Cloud и $1 AI баланса в месяц (до начала 2026).
- Далее — usage-based: размер инстанса, трафик, хранилище, исходящий трафик.
- Для небольшой платформы в начале: от $0 до $50–100/мес в зависимости от нагрузки.
- При росте базы и трафика: $100–500+/мес.

### Платёжная комиссия
- Lovable Payments (Stripe/Paddle): ~2.9%–5% + фикс за транзакцию.
- Пример: курс за $100 → комиссия примерно $3–6.
- Управление налогами (tax) может добавлять +0.5%–3.5% в зависимости от провайдера и страны.

### Дополнительно
- Домен: ~$10–20/год.
- Email-отправка: входит в Cloud или используется Lovable Email (при необходимости).
- Внешние интеграции (аналитика, CRM, Telegram-бот и т.д.) — по необходимости.

### Итого ежемесячно после запуска
- Минимальный старт: ~$20–50/мес (подписка) + Cloud по факту.
- Средняя нагрузка: ~$100–300/мес.
- Высокая нагрузка: $500+/мес.

## Рекомендуемый подход к бюджету

1. Начать с MVP: публичный сайт + каталог + 1–2 продукта + кнопка оплаты.
2. Добавить личный кабинет и автоматический доступ после оплаты.
3. Добавить админку/CMS для самостоятельного управления контентом.
4. Расширять блог, отзывы, календарь и дополнительные продукты.

Такой поэтапный запуск снижает риски и позволяет начать продажи раньше.

## Следующий шаг

Если хочешь двигаться дальше, предлагаю начать с планирования MVP: определить точный список страниц, типы продуктов и выбрать платёжного провайдера. После этого можно составить детальный план и приступить к разработке.
